# Ashugraphy · homepage demo

A single-page site for Ashugraphy, a wedding photography and films studio in Pune: "Moments are swift. We make them stay."

Built with Next.js 16, React 19, Tailwind CSS v4, GSAP, Motion and Lenis. See `DESIGN.md` for the design system and `CLAUDE.md` for project conventions.

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000
```

`npm run dev` and `npm run build` first download the Zodiak display font from Fontshare (needs a connection on the first run) and create placeholders for any missing photos in `/images`.

The full guide (content editing, replacing images, deploying to Vercel) is completed at the end of the build.
